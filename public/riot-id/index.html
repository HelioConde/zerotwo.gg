BUSQUE UM JOGADOR POR RIOT ID.

O Riot ID identifica a conta usando nome e tag. No ZeroTwo, você pode usar esse formato para localizar um perfil público de League of Legends e abrir sua Riot Life.

PESQUISAR RIOT ID →LER O GUIA ↓
FORMATO

Nome#TAG

Digite o nome do jogador seguido de # e da tag, sem precisar usar o nome antigo de invocador.

SERVIDOR

Escolha a região

BR, NA, LAN, LAS, EUW, EUNE, KR, JP e outras regiões suportadas usam rotas diferentes.

RESULTADO

Abra a Riot Life

Depois da busca, veja rank, campeões, maestria, histórico e tendências organizadas em capítulos.

O que é um Riot ID?

O Riot ID combina duas partes: nome do jogo + tag. O formato é Nome#TAG. Esse identificador é usado entre produtos da Riot e é a forma que o ZeroTwo pede para localizar o jogador correto.

Como usar o Riot ID no ZeroTwo

  • Digite o Riot ID completo no campo de busca.
  • Selecione o servidor de League of Legends.
  • Abra a Riot Life para carregar as informações públicas disponíveis.

Pesquisar um Riot ID não comprova propriedade da conta. É apenas uma consulta pública aos dados que o produto consegue obter pelas fontes permitidas.

Por que servidor e tag importam?

Jogadores podem ter nomes parecidos, e a região influencia quais rotas de dados são consultadas. Informar a tag e o servidor ajuda a evitar ambiguidades.
