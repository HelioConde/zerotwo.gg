# ZeroTwo.gg

> **You're 01. Find your 02.**

Plataforma de compatibilidade gamer inicialmente focada em **League of Legends** e **VALORANT**. O diferencial não é apenas encontrar um duo: ZeroTwo prevê compatibilidade, observa as partidas posteriores e aprende se a dupla realmente funciona.

## Core
**Find Your 02 → 02 Sync → Gaming DNA → 02 Lab → 02 AI → Cross-Game DNA**

A visão completa está em [docs/PRODUCT.md](docs/PRODUCT.md).

## Desenvolvimento

    npm install
    npm run dev
    npm run build

A primeira versão usa dados demonstrativos. Credenciais Riot nunca devem ficar no frontend; integrações reais serão feitas por backend seguro e respeitando as políticas e opt-in aplicáveis.

## Deploy
Pushes em main disparam o workflow de GitHub Pages.
